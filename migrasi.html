Halaman ini hanya membaca sistem lama. Tidak ada data di Google Sheets yang diubah atau dihapus.

Koneksi

Hubungkan sistem lama (Apps Script) dan sistem baru (Supabase). Pengaturan disimpan di browser ini, kunci migrasi hanya selama tab terbuka.

Salin dari sistem lama

Setiap tab disalin per potongan. Tiap potongan dicek ulang dengan sidik digital (hash): kalau hasilnya sama, isi di Supabase identik sel per sel dengan Google Sheets.

Script Properties berisi token Shopee/TikTok, API key AI, SESSION_SECRET dan PASSWORD_PEPPER. Tanpa ini, integrasi marketplace mati dan semua staff harus membuat password baru.

Import file Excel

Jalur cadangan: file hasil File › Download › Microsoft Excel dari Google Sheets. Tanggal dibaca sebagai jam WIB.

File Excel tidak berisi Script Properties. Kalau perlu, tempel JSON properti di bawah (format {"NAMA": "nilai"}).

Ekspor dari Supabase

Unduh cadangan isi database baru kapan saja, dalam susunan tab yang sama dengan Google Sheets.
